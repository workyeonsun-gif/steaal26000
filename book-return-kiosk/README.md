# 📚 도서 반품 키오스크 — 연수과정용 · 직접 입력 버전 (Google Apps Script + 스프레드시트)

연수 과정에서 사용한 도서를 반품 접수하는 키오스크형 웹앱입니다.
**연수과정 정보를 직접 텍스트 입력으로만 받는 버전**입니다. QR코드 스캔으로 과정 정보를 받는 버전은 `book-return-kiosk-scan/` 폴더를 사용하세요. (두 버전은 시트 구조가 동일합니다)

- **연수 과정/기수/개강일**: 화면에서 직접 텍스트 입력 (QR/카메라 스캔 없음)
- **도서 입력 3가지 방식**: ① 카메라 또는 바코드 스캐너 ② ISBN 직접 입력(화면 키패드) ③ 도서명 검색 — 카메라가 없거나 켤 수 없는 환경에서도 사용 가능
- **스캔 결과 확인창**: 카메라/사진으로 도서를 스캔하면 인식된 제목·판정보를 확인창으로 보여주고, [✓ 맞습니다 / 🔄 다시 스캔 / ✏️ 직접 입력] 중 선택할 수 있습니다. 카메라가 실패해도 모달의 "✏️ 직접 입력" 버튼으로 바로 전환됩니다.
- **검색 결과 없는 도서**: 도서명 검색에서 결과가 없으면 ① 입력한 텍스트를 제목 그대로 추가(`미등록반품` 시트에 기록) ② ISBN 직접 입력으로 전환 ③ 카메라 스캔으로 전환 중 하나를 선택할 수 있습니다.
- **도서 정보**: ISBN으로 `도서목록` 시트에서 제목·판정보 자동 조회
- **반품 권수**: ① 화면 키패드로 직접 입력 / ② 바코드 반복 스캔으로 자동 누적 — 둘 중 택1
- **스캔 장비**: USB·블루투스 바코드 스캐너(키보드 웨지)와 기기 카메라 모두 지원
- 반품 내역은 `반품기록` 시트에, 도서목록에 없는 도서는 `미등록반품` 시트에 자동 기록됩니다.

---

## 1. 설치 방법

1. **새 Google 스프레드시트**를 만듭니다. (예: `도서반품관리`)
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 생성된 `Code.gs`의 내용을 이 폴더의 **`Code.gs`** 내용으로 교체합니다.
4. **파일 추가(＋) → HTML**을 눌러 파일 이름을 `Index`로 만들고, 이 폴더의 **`Index.html`** 내용을 붙여넣습니다.
5. (선택) 편집기 좌측 ⚙️ **프로젝트 설정 → "appsscript.json 매니페스트 표시"**를 켜고, `appsscript.json`을 이 폴더의 내용으로 교체합니다.
6. 편집기 상단에서 함수 **`setupSheets`** 를 선택하고 ▶ **실행**합니다.
   - 처음 실행 시 권한 승인 창이 뜹니다. 본인 계정으로 승인하세요.
   - 실행이 끝나면 스프레드시트에 `도서목록`, `반품기록` 시트가 생성됩니다.
7. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나(Me)**
   - 액세스 권한: 키오스크를 로그인 없이 쓰려면 **모든 사용자(Anyone)**, 조직 내부용이면 도메인 사용자
   - 배포 후 발급되는 **웹 앱 URL(`…/exec`)** 이 키오스크 주소입니다.
8. 키오스크 기기(태블릿/PC)의 Chrome에서 웹 앱 URL을 열고, 전체화면(키오스크 모드)으로 사용합니다.
   - Windows Chrome 키오스크 모드 예: `chrome.exe --kiosk "https://script.google.com/macros/s/…/exec"`

> ⚠️ 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 2. 시트 구조

### `도서목록` (도서 마스터 — 관리자가 미리 입력)

| ISBN | 제목 | 판정보 | 발간일 | 출판사 |
|---|---|---|---|---|
| 9788912345678 | 연수 교재 A | 개정 2판 | 2025-03-01 | ○○출판사 |

- ISBN 열은 텍스트 형식입니다. 13자리 ISBN을 그대로 입력하세요(하이픈 있어도 무방).
- 목록에 없는 ISBN을 스캔하면 화면에 빨간 **미등록** 배지가 표시되고, 제출 시 `반품기록`이 아닌 **`미등록반품` 시트**에 따로 기록됩니다.

### `반품기록` (자동 기록 — 도서목록에 있는 도서)

| 반품일시 | 연수과정 | 기수 | 개강일 | ISBN | 제목 | 판정보 | 권수 | 입력방식 | QR원문 | 부서 | 입력자 |
|---|---|---|---|---|---|---|---|---|---|---|---|

### `미등록반품` (자동 기록 — 도서목록에 없는 도서)

| 반품일시 | 연수과정 | 기수 | 개강일 | ISBN | 제목 | 권수 | 입력방식 | QR원문 | 부서 | 입력자 |
|---|---|---|---|---|---|---|---|---|---|---|

- 도서목록에 없는 ISBN을 스캔한 경우와, **도서명 검색 결과가 없어 사용자가 입력한 텍스트를 제목 그대로 추가**한 경우(ISBN 칸은 빈 값) 이 시트에 기록됩니다.
- 이 시트에 쌓인 ISBN/제목을 확인해 `도서목록`에 추가해두면, 다음부터는 정상 도서로 조회됩니다.

## 3. 사용 흐름 (키오스크)

1. 시작화면에서 **[📥 반품 입력]** 터치
2. **부서 선택 + 입력자** — 연수운영부 / u-러닝부 / AI디지털연수부 / 기타부서(부서명 직접 입력) 중 하나를 선택하고, 입력자 이름(선택값)을 입력 → [다음]. 부서와 입력자는 `반품기록`·`미등록반품` 시트의 `부서`·`입력자` 열에 함께 기록됩니다.
3. **연수 과정 정보 직접 입력** — 과정명·기수·개강일을 화면에서 텍스트로 입력
4. **권수 입력 방식 선택**
   - 🔢 **권수 직접 입력**: 도서 1회 입력 → 키패드로 권수 입력
   - 📖 **바코드 반복 스캔**: 같은 도서를 스캔할 때마다 권수 +1
5. **도서 입력** — 아래 3가지 중 편한 방법 사용, 목록에서 권수 수정(＋/−/터치)·삭제 가능
   - 📷 **카메라·스캐너**: ISBN 바코드를 카메라나 USB 스캐너로 스캔
   - 🔢 **ISBN 직접 입력**: 화면 키패드로 13자리 숫자 입력
   - 🔍 **도서명 검색**: 도서목록에 등록된 도서를 제목으로 검색해 선택
6. **반품 확인 → 제출** — 확인 화면에서 **[📄 PDF 저장]**(내역서 다운로드)과 **[📧 이메일 전송]**(받는 주소 입력 후 PDF 첨부 발송)도 사용할 수 있습니다. 완료 화면 후 8초 뒤 자동으로 처음 화면 복귀

> 📧 이메일 전송은 배포 계정의 Gmail로 발송되며, 처음 사용 전 Apps Script에서 메일 권한 재승인이 필요할 수 있습니다(코드 갱신 후 `setupSheets` 등 아무 함수나 한 번 실행하면 승인 창이 뜹니다).

## 4. 스캔 장비 참고 (도서 입력 단계)

- **USB/블루투스 스캐너**: "키보드 웨지" 방식(스캔 시 문자열+Enter 입력)이면 별도 설정 없이 동작합니다. 스캐너의 종료 문자(suffix)가 Enter(CR)로 설정되어 있는지 확인하세요.
- **카메라 스캔**: [html5-qrcode](https://github.com/mebjas/html5-qrcode) 라이브러리를 사용합니다. 처음 사용 시 브라우저의 카메라 권한을 허용해야 합니다.
- **사진 인식 3단계 엔진**: ① 브라우저 내장 BarcodeDetector(OS 네이티브, iOS 17+/안드로이드 크롬) ② html5-qrcode ③ 바코드 인식이 모두 실패하면 **인쇄된 ISBN 숫자를 OCR로 인식**(Tesseract.js, 첫 사용 시에만 로드)해 자동 전환합니다. 어느 단계든 성공하면 확인창을 거쳐 적용되며, 진행 상태(1차/2차/3차)가 화면에 표시됩니다.
- **⚠️ 권한을 허용해도 카메라가 안 켜질 때**: Apps Script 웹앱은 구글의 샌드박스 iframe 안에서 실행되는데, 이 iframe은 보안 정책상 실시간 카메라(getUserMedia)가 차단됩니다. 이 경우 카메라 모달의 **"📸 사진 찍어 인식"** 버튼을 사용하세요 — 기기의 카메라 앱이 열리고, 코드를 사진으로 찍으면 그 이미지에서 QR/바코드를 인식합니다. 사진 방식은 iframe 제한과 무관하게 항상 동작합니다. (사진은 코드가 화면에 크고 선명하게 나오게 찍어야 인식률이 좋습니다)

## 시트 메뉴: 선택한 행 PDF 다운로드

스프레드시트를 열면 상단에 **📦 반품 키오스크** 메뉴가 생깁니다. (코드 붙여넣기 후 시트를 새로고침하세요. 첫 실행 시 권한 승인 필요)

| 메뉴 | 동작 |
|---|---|
| ☑️ 선택 체크박스 추가/정비 | `반품기록`·`미등록반품` 시트 맨 끝에 **선택** 체크박스 열을 추가합니다 (최초 1회 + 열이 어긋났을 때) |
| ✅ 전체 선택 (현재 시트) | 현재 보고 있는 시트의 모든 행을 체크 |
| ⬜ 전체 선택 해제 (현재 시트) | 현재 보고 있는 시트의 체크를 모두 해제 |
| 📄 선택한 행 PDF 다운로드 | 두 시트에서 체크된 행만 모아 키오스크 확인 화면 스타일의 PDF로 생성, `반품내역_YYYYMMDD_HHMMSS.pdf` 이름으로 다운로드 |

## 시트 메뉴: 날짜로 조회/수정 (수정이력 추적)

**📦 반품 키오스크 → 🔎 날짜로 조회/수정 (15일 이내)** 메뉴로 `반품기록`·`미등록반품` 내역을 한 화면에서 검색하고 수정할 수 있습니다.

- **검색 조건**: 날짜 / 연수과정명 / 도서명 / 입력자 — 조합해서 검색할 수 있고, 텍스트 조건은 일부만 입력해도 됩니다(공백·대소문자 무시).
- **30일 제한**: 날짜를 지정하지 않고 텍스트 조건만으로 검색하면 **검색일 기준 최근 30일 이내** 기록만 조회되며, 이 내용은 조회창 상단에 안내문으로 표시됩니다. 더 오래된 기록은 날짜를 지정해 조회하세요.

- ⚠️ 이 기능을 쓰려면 Apps Script 프로젝트에 **`Manage`라는 이름의 HTML 파일**을 추가하고 이 폴더의 `Manage.html` 내용을 붙여넣어야 합니다. (Index와 같은 방법)
- **수정 가능 기한**: 입력일로부터 **15일 이내**의 기록만 수정할 수 있습니다. 15일이 지난 기록은 🔒 잠금 표시와 함께 읽기 전용으로 보이고, 서버에서도 다시 한번 차단합니다.
- **수정 추적**: 저장하면 변경된 모든 항목이 **`수정이력` 시트**(자동 생성)에 `수정일시 | 시트 | 행 | 항목 | 변경 전 | 변경 후 | 수정자` 형식으로 기록되어, 담당자가 무엇이 어떻게 바뀌었는지 추적할 수 있습니다.
- 변경한 칸은 노란색으로 표시되며, 저장 전 확인 창에서 변경 건수를 다시 보여줍니다.
- 수정 가능 항목: 연수과정, 기수, 개강일, 권수 (미등록반품은 제목 포함)
- 기존 시트를 쓰고 있다면 `반품기록`·`미등록반품` 시트의 **QR원문 다음에 `부서`, `입력자` 열을 순서대로 직접 삽입**해주세요(수정발생/선택 열보다 앞). 새로 만드는 시트(setupSheets)에는 자동 포함됩니다.

## 키오스크: 반품 내역 조회/수정

진입화면에서 **[📥 반품 입력] / [🔍 반품 내역 조회]** 중 하나를 선택해 시작합니다.

- 조회 화면에서 기록을 검색해 **키오스크에서 직접 수정**할 수 있습니다. 날짜 없이 검색하면 최근 30일 이내만 조회되며 화면에 안내문이 표시됩니다.
- **수정 가능 조건**: 입력일로부터 **15일 이내** 그리고 시트의 **반품처리완료 체크박스가 해제**된 기록만. 잠긴 기록은 🔒 사유와 함께 회색으로 표시되고, 누르거나 저장을 시도하면 **"수정이 불가한 내역입니다. 출판미디어사업부에 연락바랍니다."** 알림창이 뜨며 [🏠 최초 화면으로 돌아가기] 버튼이 제공됩니다. (서버에서도 같은 조건을 다시 검증)
- **선택 PDF/이메일**: 각 기록 앞의 체크박스로 내역을 선택한 뒤 **[📄 선택 PDF]**(키오스크 스타일 PDF 다운로드, `반품내역_일시.pdf`) 또는 **[📧 선택 이메일]**(받는 주소 입력 후 PDF 첨부 발송)을 사용할 수 있습니다. 잠긴(수정 불가) 기록도 선택해 출력할 수 있습니다.
- **수정 추적**: 수정하면 ① `수정이력` 시트에 변경 전/후가 한 줄씩 기록되고 ② 해당 행의 **수정발생** 열에 "수정됨", **수정일** 열에 수정 시각이 표시됩니다.
- `반품기록`·`미등록반품` 시트에 **수정발생 | 수정일 | 반품처리완료(체크박스)** 3개 열이 자동 추가됩니다(setupSheets 실행 또는 첫 저장 시). 반품 처리가 끝난 행은 담당자가 **반품처리완료**를 체크해 잠그세요.
