# 📚 도서 반품 키오스크 (Google Apps Script + 스프레드시트)

연수 과정에서 사용한 도서를 반품 접수하는 키오스크형 웹앱입니다.

- **연수 과정/기수/개강일**: QR코드 스캔으로 입력 (직접 입력도 가능)
- **도서 입력 3가지 방식**: ① 카메라 또는 바코드 스캐너 ② ISBN 직접 입력(화면 키패드) ③ 도서명 검색 — 카메라가 없거나 켤 수 없는 환경에서도 사용 가능
- **스캔 결과 확인창**: 카메라/사진으로 스캔하면 인식된 내용(과정 QR: 과정명·기수·개강일 / 도서: 제목·판정보)을 확인창으로 보여주고, [✓ 맞습니다 / 🔄 다시 스캔 / ✏️ 직접 입력] 중 선택할 수 있습니다. 카메라가 실패해도 모달의 "✏️ 직접 입력" 버튼으로 바로 전환됩니다.
- **검색 결과 없는 도서**: 도서명 검색에서 결과가 없으면 입력한 텍스트를 제목 그대로 추가할 수 있고, 해당 건은 `미등록반품` 시트에 기록됩니다.
- **도서 정보**: ISBN으로 `도서목록` 시트에서 제목·판정보 자동 조회
- **반품 권수**: ① 화면 키패드로 직접 입력 / ② 바코드 반복 스캔으로 자동 누적 — 둘 중 택1
- **스캔 장비**: USB·블루투스 바코드 스캐너(키보드 웨지)와 기기 카메라 모두 지원
- 반품 내역은 `반품기록` 시트에, 도서목록에 없는 도서는 `미등록반품` 시트에 자동 기록됩니다.

---

## 1. 설치 방법

1. **새 Google 스프레드시트**를 만듭니다. (예: `도서반품관리`)
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 생성된 `Code.gs`의 내용을 이 폴더의 **`Code.gs`** 내용으로 교체합니다.
4. **파일 추가(＋) → HTML**을 눌러 파일 이름을 `Index`로 만들고, 이 폴더의 **`Index.html`** 내용을 붙여넣습니다.
5. (선택) 편집기 좌측 ⚙️ **프로젝트 설정 → "appsscript.json 매니페스트 표시"**를 켜고, `appsscript.json`을 이 폴더의 내용으로 교체합니다.
6. 편집기 상단에서 함수 **`setupSheets`** 를 선택하고 ▶ **실행**합니다.
   - 처음 실행 시 권한 승인 창이 뜹니다. 본인 계정으로 승인하세요.
   - 실행이 끝나면 스프레드시트에 `도서목록`, `반품기록` 시트가 생성됩니다.
7. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나(Me)**
   - 액세스 권한: 키오스크를 로그인 없이 쓰려면 **모든 사용자(Anyone)**, 조직 내부용이면 도메인 사용자
   - 배포 후 발급되는 **웹 앱 URL(`…/exec`)** 이 키오스크 주소입니다.
8. 키오스크 기기(태블릿/PC)의 Chrome에서 웹 앱 URL을 열고, 전체화면(키오스크 모드)으로 사용합니다.
   - Windows Chrome 키오스크 모드 예: `chrome.exe --kiosk "https://script.google.com/macros/s/…/exec"`

> ⚠️ 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 2. 시트 구조

### `도서목록` (도서 마스터 — 관리자가 미리 입력)

| ISBN | 제목 | 판정보 | 발간일 | 출판사 |
|---|---|---|---|---|
| 9788912345678 | 연수 교재 A | 개정 2판 | 2025-03-01 | ○○출판사 |

- ISBN 열은 텍스트 형식입니다. 13자리 ISBN을 그대로 입력하세요(하이픈 있어도 무방).
- 목록에 없는 ISBN을 스캔하면 화면에 빨간 **미등록** 배지가 표시되고, 제출 시 `반품기록`이 아닌 **`미등록반품` 시트**에 따로 기록됩니다.

### `반품기록` (자동 기록 — 도서목록에 있는 도서)

| 반품일시 | 연수과정 | 기수 | 개강일 | ISBN | 제목 | 판정보 | 권수 | 입력방식 | QR원문 |
|---|---|---|---|---|---|---|---|---|---|

### `미등록반품` (자동 기록 — 도서목록에 없는 도서)

| 반품일시 | 연수과정 | 기수 | 개강일 | ISBN | 제목 | 권수 | 입력방식 | QR원문 |
|---|---|---|---|---|---|---|---|---|

- 도서목록에 없는 ISBN을 스캔한 경우와, **도서명 검색 결과가 없어 사용자가 입력한 텍스트를 제목 그대로 추가**한 경우(ISBN 칸은 빈 값) 이 시트에 기록됩니다.
- 이 시트에 쌓인 ISBN/제목을 확인해 `도서목록`에 추가해두면, 다음부터는 정상 도서로 조회됩니다.

## 3. 연수 과정 QR코드 형식

QR에 아래 형식 중 하나로 내용을 담아 인쇄하면 됩니다.

| 형식 | 예시 |
|---|---|
| 구분자(권장) | `2026 신규임용연수\|12기\|2026-03-02` 또는 `2026 신규임용연수,12기,2026-03-02` |
| JSON | `{"course":"2026 신규임용연수","cohort":"12기","startDate":"2026-03-02"}` (`과정`/`기수`/`개강일` 키도 인식) |
| 일부만 | `2026 신규임용연수\|12기` → 빠진 항목(개강일 등)은 화면에서 직접 입력 |

## 4. 사용 흐름 (키오스크)

1. **반품 시작하기** 터치
2. **연수 과정 QR 스캔** — USB 스캐너로 찍거나 `📷 카메라로 스캔` 사용 (과정명·기수·개강일 직접 입력도 가능)
3. **권수 입력 방식 선택**
   - 🔢 **권수 직접 입력**: 도서 1회 입력 → 키패드로 권수 입력
   - 📖 **바코드 반복 스캔**: 같은 도서를 스캔할 때마다 권수 +1
4. **도서 입력** — 아래 3가지 중 편한 방법 사용, 목록에서 권수 수정(＋/−/터치)·삭제 가능
   - 📷 **카메라·스캐너**: ISBN 바코드를 카메라나 USB 스캐너로 스캔
   - 🔢 **ISBN 직접 입력**: 화면 키패드로 13자리 숫자 입력
   - 🔍 **도서명 검색**: 도서목록에 등록된 도서를 제목으로 검색해 선택
5. **반품 확인 → 제출** — 완료 화면 후 8초 뒤 자동으로 처음 화면 복귀

## 5. 스캔 장비 참고

- **USB/블루투스 스캐너**: "키보드 웨지" 방식(스캔 시 문자열+Enter 입력)이면 별도 설정 없이 동작합니다. 스캐너의 종료 문자(suffix)가 Enter(CR)로 설정되어 있는지 확인하세요.
- **카메라 스캔**: [html5-qrcode](https://github.com/mebjas/html5-qrcode) 라이브러리를 사용합니다. 처음 사용 시 브라우저의 카메라 권한을 허용해야 합니다.
- **⚠️ 권한을 허용해도 카메라가 안 켜질 때**: Apps Script 웹앱은 구글의 샌드박스 iframe 안에서 실행되는데, 이 iframe은 보안 정책상 실시간 카메라(getUserMedia)가 차단됩니다. 이 경우 카메라 모달의 **"📸 사진 찍어 인식"** 버튼을 사용하세요 — 기기의 카메라 앱이 열리고, 코드를 사진으로 찍으면 그 이미지에서 QR/바코드를 인식합니다. 사진 방식은 iframe 제한과 무관하게 항상 동작합니다. (사진은 코드가 화면에 크고 선명하게 나오게 찍어야 인식률이 좋습니다)
