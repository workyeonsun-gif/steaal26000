# 📚 도서 반품 키오스크 — 개인고객용 (Google Apps Script + 스프레드시트)

개인고객의 도서 반품을 접수하는 키오스크형 웹앱입니다.
연수과정용 키오스크(`book-return-kiosk/`)와 별도의 앱이며, **별도의 스프레드시트**에 설치하세요.

- **주문 정보**: 시작화면에서 **[고객명으로 시작]** 버튼으로 진입 → 고객명(필수)·주문번호(선택)·반품일자(기본: 오늘)를 직접 입력. 송장 스캔은 사용하지 않습니다.
- **도서 입력 3가지 방식**: ① 카메라 또는 바코드 스캐너 ② ISBN 직접 입력(화면 키패드) ③ 도서명 검색
- **스캔 결과 확인창**: 카메라/사진으로 스캔하면 인식된 도서의 제목·판정보를 확인창으로 보여주고, [✓ 맞습니다 / 🔄 다시 스캔 / ✏️ 직접 입력] 중 선택할 수 있습니다. 카메라가 실패해도 모달의 "✏️ 직접 입력" 버튼으로 바로 전환됩니다.
- **검색 결과 없는 도서**: 도서명 검색에서 결과가 없으면 ① 입력한 텍스트를 제목 그대로 추가(`미등록반품` 시트에 기록) ② ISBN 직접 입력으로 전환 ③ 카메라 스캔으로 전환 중 하나를 선택할 수 있습니다.
- **권 단위 상태 판정**: 같은 도서라도 "3권은 반품 OK, 2권은 접수 불가(파손)"처럼 권수를 나눠 판정·기록 (상태별로 시트에 한 행씩 기록)
- **반품 권수**: ① 화면 키패드로 OK/파손 권수를 각각 직접 입력 / ② 바코드 반복 스캔으로 자동 누적("현재 판정" 토글로 OK·파손 전환) — 둘 중 택1
- 반품 내역은 `반품기록` 시트에, 도서목록에 없는 도서는 `미등록반품` 시트에 자동 기록됩니다.

## 1. 설치 방법

1. **새 Google 스프레드시트**를 만듭니다. (예: `개인고객반품관리`)
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 생성된 `Code.gs`의 내용을 이 폴더의 **`Code.gs`** 내용으로 교체합니다.
4. **파일 추가(＋) → HTML** → 파일 이름을 정확히 `Index`로 만들고, 이 폴더의 **`Index.html`** 내용을 붙여넣습니다.
5. 함수 **`setupSheets`** 를 선택하고 ▶ 실행합니다. (최초 1회, 권한 승인 필요)
   - `도서목록`, `반품기록`, `미등록반품` 시트가 생성됩니다.
6. **배포 → 새 배포 → 웹 앱** (실행 계정: 나 / 액세스: 모든 사용자) → 발급된 `…/exec` URL이 키오스크 주소입니다.

> ⚠️ 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 2. 시트 구조

### `도서목록` (도서 마스터 — 관리자가 미리 입력)

| ISBN | 제목 | 판정보 | 발간일 | 출판사 |
|---|---|---|---|---|
| 9788912345678 | 도서 A | 개정 2판 | 2025-03-01 | ○○출판사 |

### `반품기록` (자동 기록 — 도서목록에 있는 도서)

| 접수일시 | 반품일자 | 주문번호 | 고객명 | ISBN | 제목 | 판정보 | 권수 | 상태 | 입력방식 | 스캔원문 |
|---|---|---|---|---|---|---|---|---|---|---|

- **상태** 열에는 `반품 OK` 또는 `접수 불가(파손)`가 기록됩니다.
- 한 도서를 OK/파손으로 나눠 판정하면 **상태별로 한 행씩** 기록됩니다. (예: OK 3권 1행 + 파손 2권 1행)

### `미등록반품` (자동 기록 — 도서목록에 없는 도서)

| 접수일시 | 반품일자 | 주문번호 | 고객명 | ISBN | 제목 | 권수 | 상태 | 입력방식 | 스캔원문 |
|---|---|---|---|---|---|---|---|---|---|

- 도서목록에 없는 ISBN을 스캔한 경우와, **도서명 검색 결과가 없어 사용자가 입력한 텍스트를 제목 그대로 추가**한 경우(ISBN 칸은 빈 값) 이 시트에 기록됩니다.

## 3. 사용 흐름 (키오스크)

1. 시작화면에서 **[고객명으로 시작]** 터치
2. **주문 정보 입력** — 고객명(필수)·주문번호(선택)·반품일자(기본: 오늘) 직접 입력
3. **권수 입력 방식 선택** — 🔢 직접 입력 / 📖 바코드 반복 스캔
4. **도서 입력 + 권 단위 상태 판정**
   - 📷 카메라·스캐너 / 🔢 ISBN 직접 입력 / 🔍 도서명 검색 중 편한 방법 사용
   - **직접 입력 모드**: 키패드에서 ✓ 반품 OK 권수와 ✕ 접수 불가(파손) 권수를 각각 입력 (칸을 터치해 전환)
   - **반복 스캔 모드**: 화면의 **"현재 판정"** 토글(✓ 반품 OK / ✕ 접수 불가)을 선택해 두면, 스캔할 때마다 그 판정의 권수가 +1 — 멀쩡한 책을 다 스캔한 뒤 토글을 "접수 불가"로 바꾸고 파손본을 스캔하면 됩니다
   - 목록에서 OK/파손 권수를 각각 ＋/−로 수정·삭제 가능 (둘 다 0이 되면 자동 삭제)
5. **반품 확인 → 제출** — 파손·미등록 도서가 있으면 경고 문구로 다시 알려줍니다. 확인 화면에서 **[📄 PDF 저장]**(내역서 다운로드)과 **[📧 이메일 전송]**(받는 주소 입력 후 PDF 첨부 발송)도 사용할 수 있습니다. 완료 후 8초 뒤 자동으로 처음 화면 복귀

> 📧 이메일 전송은 배포 계정의 Gmail로 발송되며, 처음 사용 전 Apps Script에서 메일 권한 재승인이 필요할 수 있습니다(코드 갱신 후 `setupSheets` 등 아무 함수나 한 번 실행하면 승인 창이 뜹니다).

## 4. 스캔 장비 참고 (도서 입력 단계)

- **USB/블루투스 스캐너**: 키보드 웨지 방식이면 별도 설정 없이 동작합니다. 종료 문자(suffix)가 Enter(CR)인지 확인하세요.
- **카메라 스캔**: [html5-qrcode](https://github.com/mebjas/html5-qrcode) 사용. 첫 사용 시 브라우저 카메라 권한을 허용해야 합니다. 카메라가 없거나 권한이 없는 환경에서는 ISBN 직접 입력·도서명 검색을 이용하세요.
- **사진 인식 3단계 엔진**: ① 브라우저 내장 BarcodeDetector(OS 네이티브, iOS 17+/안드로이드 크롬) ② html5-qrcode ③ 바코드 인식이 모두 실패하면 **인쇄된 ISBN 숫자를 OCR로 인식**(Tesseract.js, 첫 사용 시에만 로드)해 자동 전환합니다. 어느 단계든 성공하면 확인창을 거쳐 적용되며, 진행 상태(1차/2차/3차)가 화면에 표시됩니다.
- **⚠️ 권한을 허용해도 카메라가 안 켜질 때**: Apps Script 웹앱은 구글의 샌드박스 iframe 안에서 실행되는데, 이 iframe은 보안 정책상 실시간 카메라(getUserMedia)가 차단됩니다. 이 경우 카메라 모달의 **"📸 사진 찍어 인식"** 버튼을 사용하세요 — 기기의 카메라 앱이 열리고, 바코드를 사진으로 찍으면 그 이미지에서 ISBN을 인식합니다. 사진 방식은 iframe 제한과 무관하게 항상 동작합니다. (사진은 바코드가 화면에 크고 선명하게 나오게 찍어야 인식률이 좋습니다)

## 시트 메뉴: 선택한 행 PDF 다운로드

스프레드시트를 열면 상단에 **📦 반품 키오스크** 메뉴가 생깁니다. (코드 붙여넣기 후 시트를 새로고침하세요. 첫 실행 시 권한 승인 필요)

| 메뉴 | 동작 |
|---|---|
| ☑️ 선택 체크박스 추가/정비 | `반품기록`·`미등록반품` 시트 맨 끝에 **선택** 체크박스 열을 추가합니다 (최초 1회 + 열이 어긋났을 때) |
| ✅ 전체 선택 (현재 시트) | 현재 보고 있는 시트의 모든 행을 체크 |
| ⬜ 전체 선택 해제 (현재 시트) | 현재 보고 있는 시트의 체크를 모두 해제 |
| 📄 선택한 행 PDF 다운로드 | 두 시트에서 체크된 행만 모아 키오스크 확인 화면 스타일의 PDF로 생성, `반품내역_YYYYMMDD_HHMMSS.pdf` 이름으로 다운로드 |

## 시트 메뉴: 날짜로 조회/수정 (수정이력 추적)

**📦 반품 키오스크 → 🔎 날짜로 조회/수정 (15일 이내)** 메뉴로 특정 날짜(입력일 기준)의 `반품기록`·`미등록반품` 내역을 한 화면에서 조회하고 수정할 수 있습니다.

- ⚠️ 이 기능을 쓰려면 Apps Script 프로젝트에 **`Manage`라는 이름의 HTML 파일**을 추가하고 이 폴더의 `Manage.html` 내용을 붙여넣어야 합니다. (Index와 같은 방법)
- **수정 가능 기한**: 입력일로부터 **15일 이내**의 기록만 수정할 수 있습니다. 15일이 지난 기록은 🔒 잠금 표시와 함께 읽기 전용으로 보이고, 서버에서도 다시 한번 차단합니다.
- **수정 추적**: 저장하면 변경된 모든 항목이 **`수정이력` 시트**(자동 생성)에 `수정일시 | 시트 | 행 | 항목 | 변경 전 | 변경 후 | 수정자` 형식으로 기록되어, 담당자가 무엇이 어떻게 바뀌었는지 추적할 수 있습니다.
- 변경한 칸은 노란색으로 표시되며, 저장 전 확인 창에서 변경 건수를 다시 보여줍니다.
- 수정 가능 항목: 반품일자, 주문번호, 고객명, 권수, 상태 (미등록반품은 제목 포함)

## 키오스크: 반품 내역 조회/수정

진입화면에서 **[📥 반품 입력] / [🔍 반품 내역 조회]** 중 하나를 선택해 시작합니다.

- 조회 화면에서 기록을 검색해 **키오스크에서 직접 수정**할 수 있습니다. 날짜 없이 검색하면 최근 30일 이내만 조회되며 화면에 안내문이 표시됩니다.
- **수정 가능 조건**: 입력일로부터 **15일 이내** 그리고 시트의 **반품처리완료 체크박스가 해제**된 기록만. 잠긴 기록은 🔒 사유와 함께 회색으로 표시되고, 누르거나 저장을 시도하면 **"수정이 불가한 내역입니다. 출판미디어사업부에 연락바랍니다."** 알림창이 뜨며 [🏠 최초 화면으로 돌아가기] 버튼이 제공됩니다. (서버에서도 같은 조건을 다시 검증)
- **수정 추적**: 수정하면 ① `수정이력` 시트에 변경 전/후가 한 줄씩 기록되고 ② 해당 행의 **수정발생** 열에 "수정됨", **수정일** 열에 수정 시각이 표시됩니다.
- `반품기록`·`미등록반품` 시트에 **수정발생 | 수정일 | 반품처리완료(체크박스)** 3개 열이 자동 추가됩니다(setupSheets 실행 또는 첫 저장 시). 반품 처리가 끝난 행은 담당자가 **반품처리완료**를 체크해 잠그세요.
